01. 한눈에 보기 (예습 브리프)

핵심 테제: 파이썬에서 a = MyClass()를 실행하고 a.method()를 호출할 때 일어나는 모든 마법은 C 언어로 작성된 CPython 런타임의 메모리 구조체로 설명됩니다. 모든 파이썬 객체는 PyObject 헤더(참조 카운트 ob_refcnt와 타입 포인터 ob_type)를 가지며, 메서드 호출은 함수 객체의 디스크립터 프로토콜(__get__)이 동작하여 첫 번째 인자로 인스턴스(self)를 묶은 '바운드 메서드(Bound Method)' 객체를 즉석에서 생성하는 과정입니다.

단계파이썬 문법CPython 내부 C 수준 구현메모리 상태 변화
객체 할당cls.__new__(cls)PyType_GenericNew() → PyObject_Malloc()힙에 객체 크기만큼 메모리 블록 확보, 헤더 초기화
초기화self.__init__(*args)타입 슬롯 tp_init 호출인스턴스 딕셔너리(__dict__)에 속성 슬롯 바인딩
속성 탐색instance.attrPyObject_GenericGetAttr()데이터 디스크립터 → 인스턴스 __dict__ → 비데이터 디스크립터 순서
메서드 바인딩instance.methodfunction.__get__(instance, cls)함수 포인터와 인스턴스를 래핑한 PyMethodObject 반환

02. 모든 것은 PyObject다: C 구조체 헤더

CPython에서 정수, 문자열, 함수, 클래스 인스턴스 등 모든 객체는 예외 없이 PyObject_HEAD 매크로로 시작합니다. 64비트 시스템 기준으로 8바이트의 참조 횟수(ssize_t ob_refcnt)와 8바이트의 타입 객체 포인터(struct _typeobject *ob_type)가 16바이트를 차지합니다. 파이썬의 동적 타이핑은 이 ob_type 포인터를 런타임에 역참조하여 메서드 슬롯을 찾는 방식으로 작동합니다.

PyObject 구조체 ob_refcnt (참조 카운트) ob_type (타입 포인터) 16바이트 공통 헤더

03. 인스턴스 생성 과정: __new__와 __init__

많은 입문자가 __init__이 생성자인 줄 알지만, 실제 인스턴스를 메모리에 만드는 것은 __new__입니다. C 수준에서 tp_new 슬롯이 호출되어 메모리를 할당하고 ob_refcnt를 1로 설정한 인스턴스를 반환하면, 비로소 tp_init 슬롯에 해당 인스턴스와 인자가 전달되어 필드를 초기화합니다.

__new__ (객체 생성) __init__ (초기화) tp_new / tp_init 슬롯 PyObject_Malloc

04. 디스크립터 프로토콜과 self 바인딩

파이썬의 함수(Function)는 __get__ 메서드를 구현한 비데이터 디스크립터(Non-data Descriptor)입니다. 클래스에서 직접 MyClass.func을 조회하면 일반 함수가 나오지만, 인스턴스에서 obj.func을 조회하면 함수의 __get__(obj, MyClass)가 자동 호출되어 첫 번째 인자로 obj가 고정된 MethodType 래퍼가 생성됩니다. 이것이 self를 명시적으로 넘기지 않아도 넘어가는 기계적 원리입니다.

디스크립터 프로토콜 __get__ 메서드 바운드 메서드 (Bound Method) self 자동 바인딩

05. 속성 룩업 체인(Attribute Lookup Chain)

obj.x를 평가할 때 CPython의 PyObject_GenericGetAttr 함수는 엄격한 5단계 우선순위를 따릅니다: ① 클래스 MRO에서 데이터 디스크립터(__set__ 또는 __delete__ 보유) 탐색, ② 인스턴스의 __dict__ 탐색, ③ 클래스 MRO에서 비데이터 디스크립터(함수 등) 탐색, ④ 클래스의 일반 속성 탐색, ⑤ 위가 모두 실패 시 __getattr__ 호출. 이 규칙이 파이썬 객체 지향의 모든 동작을 결정합니다.

속성 룩업 체인 데이터 vs 비데이터 디스크립터 __dict__ 우선순위 __getattr__ 폴백

빈칸 채우기

  • CPython 객체 헤더는 참조 횟수와 포인터로 구성된다.
  • 실제 메모리 할당을 담당하는 클래스 메서드는 이다.
  • 파이썬 함수가 인스턴스에 접근할 때 self를 묶어주는 메커니즘을 프로토콜이라 한다.
  • __set__이나 __delete__를 구현하여 인스턴스 __dict__보다 우선하는 디스크립터를 라 부른다.
  • 함수가 인스턴스와 결합되어 생성된 호출 가능 객체를 라 한다.
  • 정상적인 룩업이 모두 실패했을 때 최후에 호출되는 폴백 메서드는 이다.

5문항 퀴즈

1. 파이썬에서 `obj = MyClass()` 호출 시 실제로 인스턴스 메모리를 할당하는 메서드는?
정답: ②. `__new__`가 객체 할당을 담당하고, `__init__`은 할당된 인스턴스를 초기화합니다.
2. 64비트 CPython에서 표준 `PyObject` 헤더가 차지하는 기본 메모리 크기는?
정답: ①. 8바이트 참조 카운트와 8바이트 타입 포인터로 총 16바이트 헤더를 가집니다.
3. `obj.method()` 호출 시 `self` 인자가 자동으로 전달되는 원리는?
정답: ③. 디스크립터 프로토콜의 `__get__(obj, cls)`가 바운드 메서드를 생성합니다.
4. CPython 속성 룩업 체인에서 인스턴스의 `__dict__`보다 우선하여 탐색되는 것은?
정답: ④. `__set__`이 구현된 데이터 디스크립터는 인스턴스 딕셔너리보다 항상 높은 우선순위를 갖습니다.
5. 파이썬의 `@property` 데코레이터가 내부적으로 사용하는 핵심 기술은?
정답: ②. property 클래스는 대표적인 데이터 디스크립터 구현체입니다.
