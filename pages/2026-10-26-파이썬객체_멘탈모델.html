파이썬 객체 메모리 모델과 멘탈 모델 핵심 요약

핵심 명제: 파이썬에서 변수는 값을 담는 '상자'가 아니라, 힙(Heap) 메모리에 떠 있는 독립 객체(PyObject)를 가리키는 '이름표(포인터)'입니다. 인스턴스는 오직 데이터(속성)만 담으며, 메서드는 점(.) 연산자가 발동시키는 디스크립터 프로토콜에 의해 동적으로 합성됩니다.

1. 상자 멘탈 모델에서 이름표 멘탈 모델로

C 언어의 int x = 10;은 스택 프레임의 4바이트 상자에 직접 정수를 기록합니다. 반면 파이썬의 x = 10은 거대한 힙 공간에 PyLongObject를 할당하고, 네임스페이스 딕셔너리의 키 'x'에 해당 객체의 메모리 주소(포인터)를 연결합니다.

# 파이썬에서 변수 대입의 본질: 이름표 복사
a = [1, 2, 3]
b = a          # 리스트가 복사되는 것이 아니라, 동일 객체에 이름표 b가 추가됨
b.append(4)
print(a)       # [1, 2, 3, 4] -> a와 b는 물리적으로 같은 힙 주소를 가리킴!

2. 데이터와 로직의 분리와 Bound Method

클래스와 인스턴스의 물리적 분리

  • 인스턴스 메모리: 자신의 고유한 상태(인스턴스 변수)를 담는 __dict__와 클래스 포인터(ob_type)만 가집니다. 메서드 코드는 인스턴스에 복제되지 않습니다.
  • 클래스 메모리: 함수(로직)는 클래스 네임스페이스에 단 하나만 존재합니다.
  • 점(.) 연산자와 Bound Method: obj.method() 호출 시 파이썬은 디스크립터의 __get__을 발동시켜, 클래스에 있던 순수 함수에 obj를 첫 번째 인자(self)로 미리 결합한 일회용 'Bound Method' 객체를 즉석에서 생성합니다.

💡 핵심 문답 5선 (Self-Review QA)

Q1. 파이썬에서 '모든 것은 객체다'라는 말의 CPython 레벨 구현 의미는 무엇입니까?

정수, 부동소수점, 문자열, 함수, 클래스 모듈까지 모든 데이터가 C 구조체인 PyObject 헤더(참조 카운트 ob_refcnt와 타입 포인터 ob_type)를 공유하는 힙 할당 블록이라는 뜻입니다.

Q2. is 연산자와 == 연산자의 차이는 메모리 모델에서 어떻게 설명됩니까?

is 연산자는 두 이름표가 가리키는 힙 메모리 주소(id())가 정확히 동일한지 비교하고, == 연산자는 객체 내부의 __eq__ 메서드를 실행하여 담긴 값의 논리적 동등성을 비교합니다.

Q3. 파이썬 메서드에서 self를 명시해야 하는 기계적 이유는 무엇입니까?

파이썬의 메서드는 문법적인 특수 블록이 아니라 클래스에 등록된 일반 함수에 불과하기 때문입니다. 호출 시 런타임이 디스크립터 매커니즘을 통해 호출 주체 인스턴스를 첫 번째 인자로 넘겨주므로 함수 시그니처에 이를 받을 매개변수(관례상 self)가 필수적입니다.

Q4. Class.method(instance)와 instance.method()의 실행 결과는 왜 동일합니까?

instance.method()가 실행될 때 점(.) 연산자가 내부적으로 Class.__dict__['method'].__get__(instance, Class)를 호출하여 Class.method(instance, ...)와 완벽히 동일한 호출 형태로 변환하기 때문입니다.

Q5. 불변(Immutable) 객체(정수, 튜플)를 수정하려고 하면 왜 새 객체가 생성됩니까?

불변 객체는 힙에 한 번 기록되면 바이트 변경이 금지되므로, x += 1과 같은 연산 시 기존 객체를 수정하는 대신 연산 결과 값을 가진 새로운 PyLongObject를 할당하고 이름표 x의 포인터만 교체하기 때문입니다.
